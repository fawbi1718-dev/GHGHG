# سكريبتات الريلز الأولى — تصوير مع scrcpy

## تجهيز الجهاز (مرة وحدة)
1. الجوال: إعدادات → حول الهاتف → اضغط «رقم البناء» ٧ مرات → خيارات المطور → فعّل «تصحيح USB»
2. الكمبيوتر: `winget install scrcpy` (أو حمّل من github.com/Genymobile/scrcpy)
3. وصّل الكيبل، افتح cmd واكتب:
   ```
   scrcpy --record=demo.mp4 --no-audio --video-codec=h265 -m1920 --max-fps=60
   ```
4. اشتغل بالفأرة والكيبورد عالشاشة المنسوخة — التسجيل بينزل نظيف بدون اهتزاز
5. كل مشهد = ملف لوحده (أسهل بالقص). القص والكابشنز بـ CapCut

قاعدة ذهبية: سجّل بوضع OLED الغامق، وخلي بيانات الحساب التجريبي واقعية (امبيلوكس، أدفيل، فولتارين…).

## ريل ١ — المسح الضوئي (٢٥ ثانية) 🎯 الأقوى
**الهوك (٠–٢ث):** نص كبير: «جرب تدخل دواء جديد… بدون ما تكتب حرف واحد»

| الوقت | المشهد | ملاحظة تصوير |
|---|---|---|
| ٢–٥ث | شاشة قفل الجوال تفتح على إشمون مباشرة | جاهز قبل التسجيل |
| ٥–١٢ث | تبويب المخزون → زر «إدخال» → زر السكانر | حركة بطيئة وواضحة |
| ١٢–١٧ث | وجّه كاميرا الجوال لباركود حقيقي (علبة قدامك) | صوّر الجوال بموبايل تاني أو أظهر نتيجة المسح بس |
| ١٧–٢٢ث | الدواء ظهر بالحقول — الاسم والسعر مليانين تلقائي | وقّف ثانية هنا، هي اللقطة النجمة |
| ٢٢–٢٥ث | زر «حفظ بالسجل» → الصنف ظهر بالقائمة + كابشن ختامي | |

**كابشن:** «الجرد اليدوي راح زمان. باركود وحدة والدواء كامل بالمخزون 📦
إشمون — منصة الصيادلة السوريين. الرابط بالبايو 💚»
**هاشتاغات:** #صيدليات_سورية #صيادلة #أدوية #دمشق #صيدلية

## ريل ٢ — الفائض يتحول فلوس (٣٠ ثانية)
**الهوك (٠–٢ث):** نص: «هالدوايا راح تضيع عندك؟ لا، بتتباع»

| الوقت | المشهد |
|---|---|
| ٢–٨ث | تصوير يدوي سريع: رف فيه علب كميات كبيرة (موبايل عادي، مش scrcpy) |
| ٨–١٥ث | scrcpy: تبويب السوق → «نشر فائض» → اختيار الدواء والكمية والسعر |
| ١٥–٢٢ث | إشعار وصل طلب من صيدلية ثانية → قبول |
| ٢٢–٣٠ث | توكن التسليم يظهر → كابشن: «رقم تسليم مثل الشحنات، ما في لبس» |

**كابشن:** «الفائض اليوم = سيولة بكرة. انشر شو ما بتحتاجه وخلي الصيادلة يطلبوا.
عمولة صفر أول شهر — للدفعة الأولى فقط. الواتساب بالبايو»

## ريل ٣ — النت قطع وإحنا شغالين (٢٢ ثانية)
**الهوك (٠–٢ث):** فيديو: إيد بتطير وضع الطيران ✈️ + نص «شوف شو صار»

| الوقت | المشهد |
|---|---|
| ٢–٦ث | وضع الطيران مفعّل — شاشة إشمون عادية تماماً |
| ٦–١٤ث | ±١ على المخزون عدة مرات، إدخال دواء، كلها شغالة |
| ١٤–١٨ث | رجعت النت → شاشة المزامنة «تمت المزامنة» |
| ١٨–٢٢ث | نص ختامي: «مخزنك مو مربوط بخط النت» |

**كابشن:** «بالمنطقة اللي بيبقط فيها النت، البرنامج لازم يشتغل بدون نت.
إشمون بيخزن كل شي محلي وبيرجع مزامنة لحاله. الرابط بالبايو»

## نصائح المونتاج (CapCut)
- خط عربي سميك (Cairo Bold / Tajawal)، أبيض على شريط أسود شفاف
- الكابشن دايماً بالنص الثلث الأوسط (مش تحت كمان الزر مخبيه)
- مقطع ≤ ٣ ثواني بين كل قطع، وزوم بسيط ١٠٥٪ عالزر المستهدف
- صوت ترند هادئ ١٠٪ تحت التعليق الصوتي (أو بدون صوت أصلاً)
